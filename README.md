# RA6M5 五自由度机械臂控制系统

这是一个基于瑞萨 RA6M5 的五自由度机械臂控制项目。系统使用 GPT 输出 5 路 PWM 驱动舵机，通过 MPU6050 获取手部姿态，并支持离线语音控制、动作录制与掉电保存、动作回放，以及局域网页控制。

项目采用裸机主循环实现，不依赖 RTOS。

## 功能概览

- 5 路 PWM 舵机控制，逻辑角度范围为 0°～180°。
- MPU6050 姿态控制：使用加速度计和陀螺仪计算 Roll、Pitch。
- 互补滤波与角度限幅，减小姿态漂移和舵机突变。
- 离线语音命令控制夹取、释放、模式切换、动作录制和回放。
- 动作帧先存入 RAM，录制结束后批量写入 Data Flash。
- Flash 帧头包含 Magic、版本号和帧数量，用于识别有效动作数据。
- W800 Wi-Fi 模块接入局域网，并由 MCU 提供舵机控制网页。
- 串口调试输出，可查看 Wi-Fi、MPU6050、舵机及动作状态。

## 使用前配置

### 1. 配置 Wi-Fi

当前程序在 `src/hal_entry.c` 中直接向 `Wifi_ConnectSTA()` 传入测试用的 SSID 和密码。请替换为自己的网络参数：

```c
Wifi_ConnectSTA("<YOUR_SSID>", "<YOUR_PASSWORD>");
```

W800 需要连接到 2.4 GHz 无线网络，并与访问网页的电脑或手机处于同一局域网。

### 2. 检查舵机安全位置

上电初始化会将 5 路舵机设置为 90°。首次使用时建议先拆除机械负载，或者关闭舵机动力电源，确认各舵机方向和零位后再安装机械结构。

### 3. 保持 MPU6050 静止

上电后程序会连续读取 50 次 MPU6050 数据，用于计算初始偏差。校准期间应保持传感器静止，否则会影响后续姿态控制效果。

## 导入与烧录

1. 安装 e² studio、FSP 6.5.0 和对应 GNU Arm 工具链。
2. 在 e² studio 中选择 `File -> Import -> Existing Projects into Workspace`。
3. 选择本项目根目录并导入工程。
4. 检查 `configuration.xml` 中的目标器件是否为 `R7FA6M5BF2CBG`。
5. 如果 e² studio 提示生成工程内容，打开 FSP Configuration 并执行 `Generate Project Content`。
6. 选择 `Debug` 或 `Release` 配置，完成构建、下载和复位。
7. 使用串口工具打开 UART7，参数设置为 115200、8 数据位、无校验、1 停止位。


## 系统启动流程

```text
初始化调试串口
    ↓
初始化并复位 W800
    ↓
连接 Wi-Fi，启动 8000 端口 TCP/HTTP 服务
    ↓
初始化 5 路 PWM 舵机
    ↓
初始化 MPU6050，并读取 WHO_AM_I
    ↓
采集 50 组数据进行零位校准
    ↓
进入 50 ms 周期的裸机主循环
```

Wi-Fi 初始化失败不会阻止舵机和 MPU6050 初始化，但网页控制将不可用。

## 控制模式

系统默认进入有线姿态控制模式。语音模块通过 UART2 输出指定字符串，用于切换模式和触发动作。

| 模式 | 主要控制来源 | 说明 |
| --- | --- | --- |
| 有线模式 | MPU6050 + 语音命令 | 根据 Roll/Pitch 控制舵机，并支持录制、回放和夹爪动作 |
| 无线模式 | W800 网页或 TCP 命令 | 网页设置 5 路目标角度，程序逐步接近目标位置 |

进入无线模式后，主循环暂不执行 MPU6050 姿态控制和动作录制逻辑；切回有线模式后恢复。

## MPU6050 姿态控制

主循环约每 50 ms 读取一次 MPU6050：

1. 读取三轴加速度和陀螺仪原始数据。
2. 由加速度计算 Roll、Pitch 的绝对参考角。
3. 对陀螺仪角速度积分，得到短时间姿态变化。
4. 使用互补滤波融合两者，当前系数为 `0.98`。
5. 对小角度变化进行量化，过滤部分抖动。
6. 将 Roll/Pitch 映射到 A、C、D、E 舵机。
7. 执行 0°～180°限幅，并限制每个控制周期的角度变化量。

当前控制关系为：Roll 主要控制 E 舵机旋转，Pitch 联动控制 A、C、D 舵机；B 舵机作为夹爪，由语音命令控制。

## 语音命令

下表是 MCU 实际接收的串口字符串，不一定等同于用户说出的中文唤醒词。语音模块固件需要把识别结果配置为这些字符串，并以换行符 `\n` 结束。

| 串口字符串 | 功能 |
| --- | --- |
| `GRIP\n` | 夹爪平滑闭合到 90° |
| `RELEASE\n` | 夹爪平滑释放到 180° |
| `for\n` | 执行一次机械臂延展调整 |
| `Com\n` | 结束延展调整 |
| `Rec\n` | 开始录制动作 |
| `End\n` | 停止录制，并保存到 Data Flash |
| `Play\n` | 从 Data Flash 加载并回放动作 |
| `UnCon\n` | 切换到无线网页控制模式 |
| `Con\n` | 切换到有线姿态控制模式 |
| `S\n` 或 `s\n` | 触发紧急停止 |

## 动作录制与回放

动作帧结构包括：

```text
距离上一帧的时间间隔 + A/B/C/D/E 五路舵机角度
```

录制过程：

```text
收到 Rec
    ↓
清零 RAM 中的帧计数
    ↓
每隔约 50 ms 保存一帧舵机角度
    ↓
收到 End
    ↓
擦除动作存储区
    ↓
写入 Flash 帧头和动作帧数组
```

当前最多保存 300 帧，对应约 15 秒动作。每个动作帧占 8 字节，Flash 中为动作数据预留 8192 字节。

Flash 帧头包含：

```text
Magic = 0x4152434D（ASCII: ARCM）
Version = 1
Frame Count
Reserved
```

回放时，系统先检查 Magic 和版本号，再将动作帧从 Flash 复制到 RAM，并按照保存的时间间隔逐帧执行。

Magic 只能判断该区域是否符合预期数据格式，不能检查所有动作数据是否损坏。当前实现没有 CRC，也没有完整的写入中断恢复机制。

## 网页控制

程序通过 W800 在本机 `8000` 端口启动 TCP 服务，并由 MCU 直接返回内置 HTML 页面，不需要单独部署网页服务器。

使用步骤：

1. 给 W800 配置正确的 Wi-Fi SSID 和密码。
2. 上电后通过 UART7 日志查看 `LKSTT` 输出，确认 RA6M5/W800 获得的局域网 IP。
3. 通过语音模块发送 `UnCon\n`，切换到无线控制模式。
4. 保证电脑或手机与 W800 位于同一局域网。
5. 浏览器访问：

```text
http://<设备IP>:8000/
```

网页提供 A～E 五个角度滑块，范围为 0°～180°。滑块变化后，浏览器发送类似以下请求：

```text
GET /set?A=90&B=90&C=90&D=90&E=90
```

无线模式会保存当前角度和目标角度，并在每个控制周期逐步移动：A、B、C 每次最多变化 4°，D、E 每次最多变化 2°，从而减小网页指令造成的突然跳变。

TCP 客户端也可以发送单路舵机命令：

```text
A:90
B:120
C:60
D:90
E:45
```

## 调试输出

UART7 会输出以下信息：

- W800 初始化、复位、联网和 TCP 服务结果；
- 设备局域网 IP 信息；
- 舵机 PWM 周期和初始化状态；
- MPU6050 初始化结果及 `WHO_AM_I`；
- MPU6050 校准结果；
- Roll、Pitch 和舵机目标角度；
- 网页请求和 TCP 接收数据。


## 使用注意事项

- 本项目控制范围是程序逻辑上的 0°～180°，实际可用范围取决于舵机和机械结构。
- 多路舵机启动电流较大，必须使用足够容量的外部电源并共地。
- MPU6050 上电校准时必须保持静止。
- W800 网页只在局域网内提供 HTTP 服务，没有身份认证，不应直接暴露到公网。
- 公开仓库前必须删除或替换源文件中的真实 Wi-Fi 凭据。
- 当前动作数据使用 Magic 和版本号检查，但没有 CRC 完整性校验。
